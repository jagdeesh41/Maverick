What We Built: Feature Walkthrough

Login & Authorization

Built

A real auth layer sits in front of every action; the login mimics how a customer would actually experience this inside a live banking app.

BankChain Assistant

Built

Gemini-powered chatbot, answers strictly scoped to BankChain / asset-tokenization questions, with graceful fallback if unreachable.

Auto-Tokenization on Consent

Built

Bank-held assets tokenize automatically once the customer consents; external assets tokenize via submitted proof — deployed as a real contract on Universal Ledger.

KYC-Gated Transfer

Built

A customer can only transfer to a buyer whose KYC is attested on-ledger by the RM — the contract itself rejects it otherwise, not just a UI warning.

Issue Token & Inheritance

Built

Customer mints a new tokenized asset and defines nominees / inheritance rules on it — a digital will.

Proof Storage on Google Cloud

Built

Every proof document (KYC, asset, transfer, claim) now lives in a private Cloud Storage bucket behind a signed URL — no more base64 blobs in the database.

Every one of these is a real, clickable flow backed by an API and a live smart contract — not a mockup.

Design

Design & Accessibility

Why Customers Would Love It

  • Login experience mimics the real customer-app flow, not a generic form
  • Guided journeys for Issue / Transfer / Inherit / Recover, with a status stepper so multi-stage approvals are legible
  • BankChain Assistant chatbot answers in-flow, scoped only to relevant questions
  • Every screen traces back to a real, working API — nothing is a static mockup

Hardened Mid-Sprint, Not Bolted On Silently

  • Accessibility: aria-pressed on role toggles, aria-label on search/note inputs — fixed and tested this sprint
  • Auth: bearer-token sessions + RM-only route gating added after we found endpoints had none
  • A CORS misconfiguration was found and fixed before this round
  • Security-by-design is the target; hardening-during-the-sprint is where we honestly started

Now running on real Universal Ledger — BFT-style consensus among known validators, no mining, no hash race.

Energy ≈ a normal microservice

Every ledger call is one ul-cli transaction, not a GPU farm.

Digitization is a net positive

Removes paper filings, notarization, and branch-visit overhead entirely.
